### Task 1 Connecting using the Windows Remote Desktop 
---
1. `Settings ---> System ---> Advanced system settings ---> Remote ---> Allow Remote Connections` and Hit Apply 

![](../../images/Pasted%20image%2020260201120341.png)

2. Head to the `Remote Desktop Connections` and Type in the name of the computer that you want to remote into 

>[!TIP]
>To get the name of the computer we can use the command `hostname`
>![](../../images/Pasted%20image%2020260201121149.png)

![](../../images/Pasted%20image%2020260201121305.png)

![](../../images/Pasted%20image%2020260201121319.png)

3. Enter the password of the helpdesk user and youw ill be prompted by the screen given below and click yes 

![](../../images/Pasted%20image%2020260201121421.png)

4. Once  you head to Patty's computer you will get a prompt and click OK 

![](../../images/Pasted%20image%2020260201121525.png)

5. Once you have clicked on OK the user Patty will be signed off and You can remote into the system 

![](../../images/Pasted%20image%2020260201121623.png)

6. To disconnect click on the cross icon
