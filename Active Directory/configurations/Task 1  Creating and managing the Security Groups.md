### Task 1 : Creating and managing the security Groups 
----
1. Head to the server machine and `open ADUC`
2. `Go to the Users folder ---> Right Click ---> New ---> Group`

![](../../images/Pasted%20image%2020260201095423.png)

![](../../images/Pasted%20image%2020260201095507.png)


>[!TIP]
>#### Security Groups 
>This are the groups that are formed based on a permission that is used to perform a specific task or functions 
>#### distribution group 
>This are the groups that are used when sending the notifications to a specific group of people 

3. Create the following groups `HR, Personal`
4. `Double Click on the HR` and Head to the pane `Managed By` and Select `Change`, This will Choose the Person who will be Responsible for this group 

![](../../images/Pasted%20image%2020260201100317.png)

>[!NOTE]
>In my case it is the **helpdesk account** that was created during the earlier writeup

5. Go to the `members` pane and add the user named `Patty`, Also Add Patty to the personal group
