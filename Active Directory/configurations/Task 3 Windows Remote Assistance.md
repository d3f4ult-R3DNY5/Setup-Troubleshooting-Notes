### Task 3 Windows Remote Assistance
---
1. Search for `Allow remote assistance to be sent from this computer`  in the taskbar search on `E-PC-02`

![](../../images/Pasted%20image%2020260201154826.png)

2. Click on `Invite Someone to connect to the PC and help you or offer to help` and Do the following 

![](../../images/Pasted%20image%2020260201155025.png)

3. Click on Save this invitation as a file and save it to your preferred location

![](../../images/Pasted%20image%2020260201155125.png)

#### Using the users drive from another PC

4. Go to the file explorer and search `\\<desktopname>\C$` in my case it is the `\\E-PC-02\C$`
5. Head to the `E-PC-01` , And in the taskbar search `Invite Someone to connect to the PC and help you or offer to help` and Click on `Help someone who has invited you`
![](../../images/Pasted%20image%2020260201160344.png)

6. Now using the `\\E-PC-02\C$` in file explorer navigate to where the invitation file is located and Type the password that is visible on the E-PC-02 machine

![](../../images/Pasted%20image%2020260201160723.png)

7. From here you can see what the user is doing and guide them through to help the user in the troubleshooting process , Alternatively you can chat or Request the control to perform the actions themselves 

![](../../images/Pasted%20image%2020260201160955.png)
